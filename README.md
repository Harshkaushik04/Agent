This project aims to make implementation of ai agent from scratch(highly inspired by COALA paper:https://arxiv.org/abs/2309.02427)
Agent folder: initial implementation of agent backend 
conversation-model foler: implementation of web frontend for doing inference with DeepSeek-R1-Distill-Qwen-7B-Q4_K_M
Agent-with-ui: combining agent backend and frontend
other folders are for testing stuff
